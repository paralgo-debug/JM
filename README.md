Site estático (HTML, CSS e JS). Para publicar no GitHub Pages: Settings > Pages > Deploy from branch > main / root.

- Cores da marca: `style.css` (`:root`)
- Antes e depois: `img/antes-N.jpg` e `img/depois-N.jpg` (N de 1 a 6)
